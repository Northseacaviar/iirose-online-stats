# 网页 JS —— iirose 浏览器侧采集脚本

注入 iirose 网页的小脚本(用站点自带的「自定义 JS」功能运行):按与终端 `stats` 同源的公式每 600 秒上报六项全站指标到本机采集服务,并在页面右下角显示悬浮面板(实时人数 + 六项瓦片 + 轻量走势图)。面板图例可点:点一下隐藏该线,再点显示(选择记在浏览器本地)。

脚本明文、无隐藏行为、不含账号信息,可直接审计。

## 安装

1. iirose 网页内 `Ctrl+S` 打开内置终端
2. `js -s` 回车 —— 打开「自定义 JS」开关
3. `js` 回车 —— 粘贴脚本地址:

   ```
   http://127.0.0.1:8080/js/collector.js
   ```

页面刷新后生效。停用:终端 `js -s` 关闭开关,或刷新后弹窗点移除。

## 前提

数据发往 `127.0.0.1:8080`,需配合 [../app/](../app) 本地端使用;没有本地端时只有实时瓦片、没有历史曲线。脚本可分享,对方需配自己的本地端。

## 脚本内可调常量

| 常量 | 默认 | 说明 |
| --- | --- | --- |
| `INTERVAL_MS` | 600000 | 采集/上报间隔(毫秒) |
| `BTN_RIGHT` / `BTN_BOTTOM_PX` | `12px` / `140` | 悬浮按钮位置 |
| `ENDPOINT` / `SERIES_URL` / `DASHBOARD` | `http://127.0.0.1:8080/…` | 本机服务地址 |

控制台 `iiroseStats.now()` 立即算一次并上报。
